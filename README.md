## Лабораторні роботи з дисципліни "Алгоритмізація та програмування, ч.1"

## Виконав: Старак Марко Ростиславович(ІР-14)
## Лабораторна робота №7 (Варіант 8)

Організація складу з коробками:
Стек коробок, де можна дістати
лише верхню коробку.

Замовлення у ресторані:
Замовлення виконуються в
порядку їх надходження.
